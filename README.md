# GOODFORM landing page

A responsive, animated landing page for a fictional independent creative studio. The visual direction, studio name, copy, colors, and project art are all editable in the source.

## Run locally

```sh
npm install
npm run dev
```

## Customize

- Update the brand, page copy, work cards, and services in `src/App.jsx`.
- Adjust color, spacing, typography, and responsive styles in `src/styles.css`.
- The React Bits `BlurText` component lives in `src/components/BlurText.tsx`.
- `ShimmerButton` in `src/App.jsx` is adapted from 21st.dev's public shimmer-button example.
- Motion animations use the `motion` package.
